# 3D Garden Designer

Design your garden or yard to scale in chat, then walk through it in 3D.

## Use it

1. Install the plugin, then connect 3D Garden Designer using Claude's connection and authentication flow.
2. Ask Claude in plain words, for example: "Design my 15 by 10 meter backyard with a patio, a lawn and a path to the shed, and show it in 3D."
3. Claude uses the included skill: it looks first, shows what it plans to change, and asks for your approval before making changes.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://3dgardendesigner.com/mcp. Tool requests are handled by 3D Garden Designer (https://3dgardendesigner.com/privacy). This bundle contains no separate storage service.
